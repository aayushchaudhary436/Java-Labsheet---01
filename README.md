# BCA201P – Foundations of Java Development
## Lab Sheet-01 Solutions (Assignments 1–30)

Each assignment is provided as a separate Java source file:
- `Assignment01.java` through `Assignment30.java`

## Requirements
- JDK 21 or higher
- VS Code, Eclipse, or IntelliJ IDEA

## Compile and run
Open a terminal in this folder. For example, to run assignment 1:

```bash
javac Assignment01.java
java Assignment01
```

For another assignment, replace `01` with its two-digit assignment number.

Most programs take input from the keyboard. Follow the prompts and enter the requested values.

## Before submitting
1. Replace the sample name, age, and college in `Assignment01.java` with your own correct details.
2. Read each program and test it with sample inputs.
3. Submit source code and corresponding output as required by your lab instructions.

## Notes
- Assignment 16 applies the stated percentage rate to the full income amount for the matching income range.
- Assignment 25 treats non-zero integers as `true` and zero as `false`; it supports `&` (AND) and `|` (OR).
- Assignment 15 checks positive three-digit Armstrong numbers, as requested.
